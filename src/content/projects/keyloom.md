An open-source library of 40+ animated video scenes — each one a copy-pasteable React component — plus a browser Studio to assemble them on a timeline.

## Features

- Text animations, animated charts, chat mockups, tweets, device frames, cards, terminals, QR codes
- Per-clip styling, transitions (fade, swipe, zoom), and stackable effects (Ken Burns and friends)
- Project save/load as JSON, MP4 export, Whisper captions, split-screen maker
- Registry-driven docs: previews drop straight onto the timeline
- Agent-friendly typed props plus a local MCP server, so coding agents can direct reels too

## Stack

Next.js 16, React 19, Tailwind 4, shadcn/ui, Remotion 4, FFmpeg.wasm; Bun + Turborepo monorepo. Live at keyloom.app, built with the Experience Company (GAIA) ecosystem.
